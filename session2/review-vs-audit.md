A code review focuses on checking code or documentation changes to ensure they meet the requirements, are readable, and do not contain obvious issues. For example, in my Pull Request #2, I reviewed the traceability note in session2/traceability-note.md and provided feedback on the reviewer evidence section. In contrast, a formal configuration audit (FCA/PCA) is a more structured process that verifies whether the complete software configuration meets specified requirements and whether all required items and records are complete and consistent.
